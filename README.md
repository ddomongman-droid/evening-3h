# 🌙 저녁 3시간

퇴근 후 3시간을 **아침에 계획**하고 **저녁에 체크**하는 모바일 웹앱. 기록은 구글 시트에 앱과 같은 색깔로 쌓입니다.

- 하루 = 고정 3칸: 1시간 · 2시간 · 3시간 (시각은 그날그날 다르므로 표시하지 않음)
- 카테고리 6개: 💼 사업 · 🤖 AI학습 · 📚 독서 · 🏃 운동 · 🎬 영상 · ✨ 기타
- 칸마다 **무엇을 할지(카테고리 + 한 줄 메모)** 와 **결과(✓ 했음 / △ 일부 / ✕ 못함)** 만 기록합니다. 계획과 다른 일을 했으면 그냥 바꿔 적으면 됩니다.
- 달성률 = (했음 1 + 일부 0.5) ÷ 오늘까지 계획한 칸

## 화면
| 탭 | 내용 |
|---|---|
| 📅 주간 | 오늘 카드(바로 체크) + 월~일 7줄 × 3칸 주간 보드 + 이번 주 달성률·카테고리별 시간 |
| 🗓️ 1년 | 12개월 × 31일 색칠 지도, 카테고리별·월별 시간 |
| ⚙️ 설정 | 시작 시간, 구글 시트 연결, 백업 |

## 구글 시트 연결 (처음 한 번, PC에서)
1. 구글 시트에서 새 스프레드시트를 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고 원래 코드를 지운 뒤 [`apps-script.gs`](apps-script.gs) 내용을 붙여넣습니다.
3. 맨 위 `SECRET`을 원하는 비밀번호로 바꾸고 저장합니다.
4. 함수 선택에서 `setup`을 고르고 ▶ 실행 → 권한을 허용합니다. 시트 모양이 만들어집니다.
5. **배포 → 새 배포 → 웹 앱**을 고르고 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 배포합니다.
6. 웹 앱 URL과 비밀번호를 앱 ⚙️ 설정에 넣고 **연결하고 전부 보내기**를 누릅니다.

> 스크립트를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

### 시트 구성
- **저녁기록**: 앱의 주간 보드와 같은 모양입니다 (하루 1줄, 칸 3개, 주차별 달성률).
  - 달성 칸: 1시간을 했으면 **김**, 2시간은 **새**, 3시간은 **별**을 적습니다. 3시간 모두 했으면 **김새별**(노란 칸), 2시간만 했으면 김새·김별·새별처럼 적힙니다. △ 일부는 달성으로 치지 않습니다.
  - 칸 색깔: 진한 색 = 했음, 반만 진한 색 = 일부, 연한 색 = 체크 전, 회색 취소선 = 못함
- **한눈에 1년**: 12개월 × 31일 칸을 그날 가장 많이 한 카테고리 색으로 칠합니다. 월별·연간 카테고리 시간도 함께 나옵니다. 칸에 마우스를 올리면 그날 기록이 보입니다.
- **_data** (숨김): 원본 데이터입니다. 앱이 다른 기기와 동기화할 때 씁니다. 지우지 마세요.

## 저장 방식
- 기록은 폰(localStorage `evening3h-v1`)에 먼저 저장되고, 1.5초 뒤 시트로 자동 전송됩니다. 오프라인이면 대기했다가 다시 보냅니다.
- 앱을 열 때 시트에서 최신 기록을 받아오므로 폰과 PC가 같은 기록을 봅니다 (날짜별로 더 최근에 고친 쪽이 이깁니다).
